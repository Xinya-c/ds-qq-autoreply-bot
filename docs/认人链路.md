# 认人链路（"你还记得 XXX 吗"）

代码：`qq_autoreply.py` 的 `_prompt()`（认人段）+ `memory.py` 的 `find_person()` /
`person_brief()` / `tie_line()`。

---

## 一、怎么定位"他说的是谁"

按可靠性从高到低试三种，命中就停：

| # | 入口 | 例子 | 说明 |
| --- | --- | --- | --- |
| ① | **QQ 号** | 「你还记得 3207399168 吗」 | 最准，正则 `\d{5,12}` |
| ② | **名字 / 备注** | 「你还记得姚明希吗」 | 名字索引，取命中最长的（「小猪佩奇」不会被认成「小猪」） |
| ③ | **上文点名** | 你：姚明希啊 → 你：你想起来他是谁了没 | 本条没名字，回看最近 3 条**对方**消息 |

③ 只在有"考记性"的词时才回看（`RECALL_CUES`：记得／认识／想起来／是谁／谁啊／
他是／她是／那人／这人／啥人／哪位）。**顺口提到名字不触发**——"姚明希刚才
说他要睡了" 不会去翻他的档案，否则每句话都在查人。

名字从哪来（三处合并）：

```
好友备注     姚明希 / 康程锦 / 胡子超      ← 扫好友列表时记
好友昵称     Changin丶Lin / 老婆大人        ← 同上
归档里的昵称  大🍬呗 / 摸鱼王               ← 从历史消息里解析
```

**备注最容易漏**：它在 `get_friend_list` 里，而 `scan_new_friends()` 自己也拉了一次
列表。两处都要调 `_remember_friend_aliases()`，漏一处就会出现"备注认不出来"
（2026-10-25 踩过：姚明希认不出，因为他昵称是五个全角空格，只有备注能认）。

别名只在内存里，重启后靠扫描重建。认不出来时会自愈：刷一次好友列表（60 秒节流）。

## 二、能说多少（隐私分级）

**认人可以，爆料不行。** 按"是否在同一个场合"定，不是按"谁在问"：

| 场景 | 能给什么 |
| --- | --- |
| 主人私聊 | 全套：私聊档案 + 群档案 + 发言 + 具体事 |
| 群聊（**包括主人问**） | 只给这个群里他说过的话 |
| 非主人私聊 | 只给"共同群"里的公开内容 |
| 没有共同场合 | 不认（本来就不该知道） |

场景优先于身份：主人在群里问，也不能把别人的私聊抖在群里。

## 三、给模型看什么（顺序就是权重）

```
他最开始来找你时说的（这几句最能说明他是谁）：你会背出师吗 / 水浴后颜色…
他跟你聊过的具体事：我给你三个盒子，只有一个里面有糖…要不要换二号？
（他跟你在私聊里说过的有 66 条，不算陌生）
他最近跟你说过：不是刚说了嘛 / 啥子鱼 / 你连我名字都记不住？
```

**「最开始」必须在最前面**。实测只给"最近说过"（全是抱怨）时，模型只会说
"好像有点耳熟"；给上最早那句"你会背出师吗"，它才能说"背出师表那个"。

「具体事」挑内容最具体的两句（他问过的题、做过的实验）。淘口令/链接会被
过滤（汉字占比 < 50%）。

## 四、两个容易踩的坑

**① 认出来了，但答得很虚**

日志里看到 `认人：姚明希（3207399168） → 注入 4 行（全套）` 说明**认出来了**。
如果回复还是"不记得"，那问题在生成侧，不在检索侧。常见原因：它前面刚说过
几次"不记得"，为了自洽继续不记得。

对策：prompt 里给**口气示范**（"照这个口气：哦——盒子里有糖那个啊，记得"），
而不是只写"不准说不认识"。示例比规则有效，这是调人格时验证过的结论。

**② 回声被当成旧记忆**

```
问「你想起来他是谁了没」 → 召回「你想起来他是谁了不」
```

那是自己上一句的复述，注入进去只会让模型重说一遍。`_is_echo()` 过滤：
**时间很近（10 分钟内）+ 字面高度相似（≥0.55）** 两个条件同时成立才丢。
三天前问过一模一样的问题值得提醒，刚才那句换个说法没有价值。
